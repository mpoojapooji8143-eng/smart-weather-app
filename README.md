# Smart Weather App 🌦

A modern weather web application that displays real-time weather information using OpenWeather API.

## Features

✔ Search weather by city  
✔ Get weather using current location  
✔ Dynamic background based on weather  
✔ Real-time temperature, humidity, wind speed  
✔ Responsive UI  

## Technologies Used

HTML  
CSS  
JavaScript  
OpenWeather API

## How to Run

1. Download project
2. Open index.html in browser
3. Enter city name
4. View weather details
