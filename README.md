🌦 Smart Weather App

A **modern and responsive weather web application** that displays real-time weather information for any city in the world.
This project uses the **OpenWeather API** to fetch live weather data and provides a clean, user-friendly interface.



 🚀 Live Features

✔ Search weather by **city name**
✔ Get weather using **current location (Geolocation)**
✔ **Dynamic background** that changes according to weather
✔ Displays **temperature, humidity, wind speed, and weather description**
✔ **Weather icons** for better visualization
✔ **Responsive design** for desktop and mobile devices
✔ Smooth UI with **modern card design and glow effects**

## ⚙ How It Works

1. User enters a **city name** in the search box.
2. JavaScript sends a request to the **OpenWeather API**.
3. API returns real-time weather data.
4. The app displays:

   * Temperature
   * Weather condition
   * Humidity
   * Wind speed
5. Background image automatically changes based on the weather condition.
